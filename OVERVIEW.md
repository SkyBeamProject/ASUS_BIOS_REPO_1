# Overview

An archive of modded ASUS BIOS files and related firmware assets. Use as a reference or backup store — see `README.md` for model mapping, version notes, and any flashing guidance.

⚠️ Flashing BIOS can brick hardware. These files are modded and are **not** official factory firmware; only flash a BIOS that matches your exact model and revision, and follow the manufacturer's procedure.
